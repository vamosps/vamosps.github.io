# Vamos JEWELRY 💎 — Luxury E-Commerce & Management System

Official storefront and administration dashboard for **Vamos JEWELRY** (طقم كابلز لاكوست الفاخر).

## ✨ Features
- **Luxury Responsive Storefront (`index.html`)**:
  - Uncropped high-definition jewelry showcases.
  - Multi-variant color selection with dynamic reactive previews.
  - Multilingual support (Arabic, English, Hebrew) with automatic device language detection.
  - Instant COD ordering with live city/zone delivery fee calculations (West Bank, Jerusalem, 48 Areas).
  - Cash register audio celebrations & confetti fanfare on purchase.
  - Direct WhatsApp order synchronization with pre-formatted message and unique order IDs.
  - Multi-platform conversion tracking (Meta, TikTok, Snapchat, GA4) with budget-optimized low-cost bid strategies.

- **Pro Operations Dashboard (`admin.html`)**:
  - Live Supabase Realtime cloud database synchronization.
  - URL hash routing with refresh (F5) state persistence.
  - Advanced order status workflow (New, In-Transit with Courier, Delivered, Cancelled).
  - Bulk order selection, batch status updates, and printable multi-waybill slips (A4 2-per-page format).
  - Built-in POS system for fast phone/direct manual order entries.
  - Customers directory with repeat buyer metrics and instant WhatsApp links.
  - Catalog product and color variants manager.
  - One-click Arabic-supported Excel (CSV) data exports.
  - Progressive Web App (PWA) installable on iOS and Android.

## 🚀 Deployment
Host directly with GitHub Pages, Vercel, Netlify, or custom domain.
